# Human checklist (10 yes/no, after a 15-minute test with the phone)

Do a normal short workout with the live voice on, phone in your hand or pocket, screen kept on. Include, on purpose: two set reports ("sixty, five"), one "sixty... [pause] five", one correction ("sixty, no, sixty-five"), one "we are not skipping anything", one interruption while the coach is talking, one "yeah" or cough while it talks, one Hinglish sentence, and one rest period. Then answer, honestly, yes or no:

| # | Question | Yes / No |
|---|---|---|
| 1 | Did it ever answer something I did not say? | |
| 2 | Did it ever change my workout (skip, swap, log a wrong set) without me asking? | |
| 3 | Did it wait when I said "sixty... five" (a pause in the middle of a set report)? | |
| 4 | Could I cut it off by talking, and did it drop what it was saying? | |
| 5 | Did a "yeah" or a cough stop it when it should have kept going? (Yes = bad) | |
| 6 | Did it speak at a good moment after the rest, and only once? | |
| 7 | Did it stay short during a set? | |
| 8 | Did Hinglish sound natural, both what it understood and how it answered? | |
| 9 | Did it remember something from earlier in this session, and from a previous one? | |
| 10 | Did it ever sound like a form-filler instead of a coach? (Yes = bad) | |

Scoring: questions 1, 2, 5, 10 are "good when NO"; the others are "good when YES". Count the good answers. **8 or more out of 10 = pass.** Write anything odd (what you said, what it did, roughly when) under the table: those lines go straight into docs/ERROR_LEDGER.md.
